# Анализ RFSD: 1000 строк × 20 колонок

Проект для учебного задания по анализу данных на основе **Russian Financial Statements Database (RFSD)**.

Источник: https://github.com/irlcode/RFSD

## Что сделано

- потоково загружаются только 1000 строк RFSD, содержащих 15 или более значений в столбцах;
- перед анализом оставляются ровно 20 числовых финансовых колонок;
- рассчитывается описательная статистика;
- строятся 3 гистограммы и определяется количество выбросов по правилу IQR;
- строится матрица корреляции всех 20 колонок;
- строится scatter plot с линией регрессии для чистых данных и отфильтрованных по 99-процентному перцентилю;
- 2 данных диаграммы рассеивания сильно отличаются, поэтому попарно строится новая матрица корреляции на основе данных без выбросов

## Почему streaming

Полный RFSD содержит десятки миллионов строк и несколько гигабайт Parquet-файлов. Поэтому полный датасет не скачивается. Используется streaming-режим Hugging Face Datasets и берутся первые 1000 доступных записей.

> Важно: авторы RFSD предупреждают, что данные внутри года не перемешаны. Поэтому первые 1000 строк нельзя считать случайной репрезентативной выборкой всей совокупности фирм. Результаты являются exploratory analysis выбранного фрагмента.
